# Kingpin-s-Code

This repository is dedicated to Vivado FPGA projects.

## 关于在 GitHub 上寻找项目 / Finding Projects on GitHub

以下是一些在 GitHub 上找到的优质 Vivado / FPGA 相关项目，供参考：
Below are some quality Vivado / FPGA-related projects found on GitHub:

| 项目 / Project | 描述 / Description | 语言 / Language |
|---|---|---|
| [vivado-xilinx-tutorials](https://github.com/catarinaacsilva/vivado-xilinx-tutorials) | Vivado 2019.2 & Vitis 教程示例，包含 AXI-DMA、AXI-Stream 等 | VHDL |
| [Basys3_Demo_SystemVerilog](https://github.com/yigitbektasgursoy/Basys3_Demo_SystemVerilog) | Digilent Basys3 FPGA 开发板的 SystemVerilog 示例项目 | SystemVerilog |
| [fpga-verilog-projects](https://github.com/vartexdev/fpga-verilog-projects) | 使用 Vivado 的 Verilog HDL 入门到进阶 FPGA 项目合集 | Verilog |
| [pynq-examples](https://github.com/cmosinverter/pynq-examples) | PYNQ-Z2 开发板上 UART/I2C/SPI 通信接口示例，含 Vivado 硬件设计文件 | VHDL |

## 如何搜索 GitHub 上的 Vivado 项目 / How to Search for Vivado Projects on GitHub

你可以通过以下方式在 GitHub 上搜索 Vivado 相关项目：
You can find Vivado-related projects on GitHub by:

1. 访问 [github.com/search](https://github.com/search) 并搜索关键词，例如：
   - `topic:vivado`
   - `topic:fpga language:verilog`
   - `topic:xilinx`

2. 浏览 [Awesome FPGA](https://github.com/Vitorian/awesome-fpga) 等精选列表。
